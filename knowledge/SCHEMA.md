# 知识库提取规范

知识库有两类来源，提取规则不同，但产出的条目结构统一。

| 来源 | 形态 | 页数 | 提取方式 | 文件前缀 |
|---|---|---|---|---|
| `考研英语作文.pdf` | 扫描图片，无文字层 | 47 | 读渲染图逐字誊抄 | `raw-01-12` … `raw-37-47` |
| 石雷鹏笔记 ×4（英一/英二 × 大/小作文） | 有完整文字层 | 70+64+62+58 | `get_text()` 提取后人工核对 | `slp-big-e1`、`slp-big-e2`、`slp-small-e1`、`slp-small-e2` |

来源一的渲染图位于 `pages/p01.png` … `pages/p47.png`（180 DPI）。

## 一、PDF 的颜色语义（已在 p01/p02 实地确认）

| 视觉标记 | 含义 | 提取为 |
|---|---|---|
| **红色**文字（如「题目相关词」「过失行为」） | 占位符，必须用题干信息填充 | `slots`，句子里写成 `{题目相关词}` |
| **蓝色**文字（中文对照里，如「日常行为」「示范作用」「潜移默化」） | 作者要求「根据具体题目修改」的可替换词 | `swappable` |
| **黄色**荧光 | 作者方法论、使用要点、避坑提醒 | `notes` / `rules.json` |
| **蓝色**底色块 | 真题示例（已填好占位符的完整示范） | `examples` |
| 「秘密哥手把手教」 | 作者的针对性讲解 | `notes` |

## 二、绝对准则

1. **英文句子必须逐字誊抄**，不得改写、润色、补全、翻译回译。软件要把这些句子当骨架注入 AI，一个词错就全篇错。
2. 看不清的词写 `"uncertain": ["词1"]` 并在该位置用 `⟨?⟩` 标出，**绝不允许猜测填充**。
3. 中文对照句同样照抄。
4. 红色占位符在英文句里统一写成 `{题目相关词}` 这类花括号形式。
5. 页面上没有的内容，一律不得添加。

## 三、条目结构

```json
{
  "id": "big-body-positive-01",
  "page": 2,
  "section": "大作文第二段正面品质",
  "en": "Viewed within the context of everyday life, it is hardly surprising that {题目相关词} can bring considerable benefits. ...",
  "zh": "回到日常生活的语境中来看，{题目相关词}能够带来大量好处，并不值得意外。...",
  "slots": ["题目相关词"],
  "swappable": ["日常行为", "示范作用", "潜移默化", "困难和挑战", "游刃有余", "未来", "清晰"],
  "examples": [
    { "label": "16 年英语一示例", "zh": "回到日常生活的语境中来看，父母的以身作则能够带来大量好处……", "en": "" }
  ],
  "notes": ["品质类需根据具体题目，从语料包中替换这一段里的句子", "自行挑选几句，而非全写，控制好字数"]
}
```

字段说明：
- `en` / `zh`：原文照抄。若该条只有英文或只有中文，另一个留空字符串。
- `slots`：出现的红色占位符名称去重列表。
- `swappable`：蓝色可替换词列表（照抄中文原词）。
- `examples`：蓝底真题示例，`label` 写页面标注的年份（如「16 年英语一示例」）。示例只有中文时 `en` 留空。
- `notes`：该条相关的黄色荧光要点。
- `uncertain`：可选，无法辨认的词。

## 四、页面级输出

```json
{
  "page": 2,
  "title": "大作文第二段正面品质",
  "kind": "big-essay-body",
  "entries": [ /* 上述条目 */ ],
  "pageNotes": ["整页级别的黄色荧光方法论，不属于某个具体句子的"],
  "vocab": [ { "en": "energy conservation", "zh": "节能" } ]
}
```

`kind` 取值：
- `big-essay-opening` 大作文开头段
- `big-essay-body` 大作文主体段
- `big-essay-closing` 大作文结尾段
- `chart-essay` 图表作文
- `small-essay-para1` / `small-essay-para2` / `small-essay-para3` 小作文分段句库
- `small-essay-typed` 小作文按题型专项（需在条目里注明题型，如邀请类、道歉类）
- `layout` 卷面格式规范
- `vocab` 替换词表
- `method` 纯方法论页
- `transition` 过渡页/几乎空白页

## 五、已确认的方法论（p01–p02，写入 rules.json）

- 「只要你会换名词和形容词，就能少背，效率拉满」
- 「注意！可不是让你把『图片描述句』这几个字翻译成英文！而是把题目中的图画用英文自己写、自己描述」
- 「题目相关词可以是不同的英文单词，不一定全篇的题目相关词都是一样的」
- 「也有可能考材料类，就是题目给你一段文字让你写，这个时候把这幅画改成这段材料就行了」
- 「蓝色根据具体题目修改。你想不生硬，你就得换啊，必须得多加积累练习，不能既要又要，不可能说是一个神秘大模板拿到后直接啥也不学啥也不练，就直接能完美贴合所有题目」
- 「自行挑选几句，而非全写，控制好字数」
- 「每个点都可以加个连词，按自己喜欢的去加，像 first and foremost、What's more 这种，全凭个人喜好自行添加 or 不加」
- 「品质类需要根据具体题目，从语料包中替换这一段里的句子，学会积累好句子，到时候即使考到模版里没有的品质，也能换基本词汇做到以不变应万变」

## 六、石雷鹏笔记的专门约定

这四份笔记有文字层，但**体裁是范文而非模板**。直接把范文句子当模板会把题目专属内容固化进去，因此必须做骨架抽取。

### 6.1 排版特征与对应字段

| 笔记里的形态 | 含义 | 提取为 |
|---|---|---|
| `major/main/chief`（斜杠并列） | 作者给的同义替换 | `swappable`，`en` 里保留首选词 |
| 参考范文正文 | 成品句子 | 抽骨架后写入 `en` |
| 右栏逐句功能标注（如「第一句：图表形式＋数据主体＋地点＋时间」） | 句子功能说明 | `section` + `notes` |
| 「审题要点」项目符号 | 方法论 | `pageNotes` |
| 「四种语法现象」「句型句法」编号列表 | 语法得分点 | `notes`，并标明语法名称 |
| 单词释义（`judge n.评委`） | 生词表 | `vocab` |
| 参考译文 | 中文对照 | `zh`（按句对齐） |
| 「7 步法」背诵流程 | 学习方法 | `rules`，不作模板句 |

### 6.2 骨架抽取规则

从范文抽模板时，按以下顺序处理：

1. **识别题目专属内容，挖成占位符**。范文里的具体事物换成 `{题目相关词}`，具体动作换成 `[建议行动]` 这类二级占位符。
   - 原文：`inviting you to be the major judge`
   - 抽取：`inviting you to {受邀担任的角色}`
2. **保留功能骨架不动**。`I am writing for the purpose of...`、`Given is a column chart, clearly illustrating...` 这类功能句式原样保留，这是可复用的部分。
3. **斜杠替换词只取首选进 `en`**，其余全部进 `swappable`。
4. **数字与年份一律占位化**。图表范文里的 `600 million`、`from 2000 to 2008` 必须换成 `{数值}`、`{起始年份}`、`{结束年份}`，否则换题就错。
5. **一个完整段落可作为一个条目**（沿用 `big-body-campus-p11-01` 的做法），便于按字数整段选用。

### 6.3 溯源字段（本来源必填）

由于存在抽取改写，每条必须能回溯：

```json
{
  "id": "slp-chart-open-e2-01",
  "source": "slp-big-e2",
  "page": 8,
  "origin": "精讲1：全球手机市场（10 年）",
  "derived": true,
  "originalText": "Given is a column chart, clearly illustrating the remarkable contrasts in mobile-phone subscriptions between developing and developed nations from 2000 to 2008.",
  "en": "Given is a {图表类型}, clearly illustrating the remarkable contrasts in {数据主体} between {对象A} and {对象B} from {起始年份} to {结束年份}.",
  "slots": ["图表类型", "数据主体", "对象A", "对象B", "起始年份", "结束年份"],
  "swappable": ["Given is", "This is", "It is", "There is a"]
}
```

- `source`：四份笔记的标识
- `origin`：所属真题或章节名
- `derived`：`true` 表示由范文抽取而来，`false` 表示笔记里本就是模板句式
- `originalText`：**范文原句，必须逐字保留**，供人工核对抽取是否失真

### 6.4 与现有 220 条的关系

- 新条目**追加**，不覆盖原有条目
- `kind` 沿用第四节的取值，不新增
- 图表作文细分写进 `section`：静态（饼图/表格，对比排序）与动态（折线/柱状，趋势变化）
- 去重原则：功能骨架高度重合时保留信息更全的一条，并在 `notes` 注明另一来源也有类似句式

### 6.5 本来源的绝对准则

1. `originalText` 逐字照抄，不得改写。
2. 只允许把**题目专属内容**替换为占位符，功能骨架的任何词都不许改。
3. 笔记里没有的句子不得添加，不得为凑数量自造英文。
4. 中文译文照抄，不自行翻译。
5. 抽取有疑义时，宁可 `derived: false` 整句保留，也不做勉强的占位化。
