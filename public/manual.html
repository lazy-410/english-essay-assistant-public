01 · Overview

软件概览

这是一套在本机浏览器中使用的考研英语作文辅助工具：页面在本机运行，AI 与云 OCR 功能按你的配置调用相应服务。

当前核心原则：先解决“写什么”，再解决“怎么表达”。

软件不会先拿一堆模板硬拼文章。它会先确认题目、题图和任务要求，建立可核验的题面事实；再生成内容规划；随后为每个内容单元匹配合适的语言骨架；最后成文并执行字数、事实、任务覆盖、重复表达、格式与来源等自检。

V1扫描讲义结构化层

47 页、378 条模板、207 个词条，用于检索、出处追溯与卷面规范。

V2写作生产知识层

131 条方法备注、372 条生产骨架、1103 个变体、269 个实例。

4 层可解释生成链

题面事实 → 内容规划 → 语言骨架 → 成文自检。

英一 / 英二分方向背诵

首次打开先选方向，只显示该方向要背的内容，进度可背满。

372学习卡片

按写作顺序切成学习单元，进度存服务端，可导出打印。

复盘成文后模块解析

写完即给出模块组装流程、缺口建议与本次用到的模板句。

批改自己写的也能改

拍照上传 → 校对识别 → 确认后按讲义规则分级修改，每条附依据。

A4打印 PDF

背诵卡片与行文精讲均可导出，中英文可选取、可搜索。

V1 与 V2 不是两个可切换的软件版本。 V1 是原扫描讲义的结构化检索层；V2 是当前默认成文链使用的写作方法、骨架、变体与实例层。两者共同服务于同一个界面。

02 · Editions

03 · Quick Start

启动软件

软件通过本机服务运行。请先完整解压，再从项目根目录启动（Windows 单文件版只需把 exe 与同目录文件一起解压，双击 exe）。

完整解压压缩包

不要直接在压缩软件的预览窗口里运行，也不要只拖出一个 start.bat。目录中的 public、knowledge、exam-assets、assets 等文件需要保持完整。

Windows 双击 start.bat

单文件版双击 考研英语作文助手.exe 即可；免安装版与完整版双击 start.bat 会优先使用包内运行时；精简版会调用系统中的 Node.js 18+。macOS 请双击 start.command，Linux 请执行 ./start.sh。

等待浏览器自动打开

默认地址为 127.0.0.1:7654。若没有自动打开，请手动在浏览器地址栏输入该地址。

保持命令窗口开启

黑色命令窗口就是本地服务。关闭它后页面会失去连接；使用结束时可在该窗口按 Ctrl + C 停止服务。单文件版双击 exe 的窗口同理。

首次使用：激活你的副本

正式发行包带激活码授权。首次启动且尚未激活时，浏览器会打开「激活」页面（此时首页与各功能页暂不可用），按下面两步完成：

输入激活码

激活码是发放软件时一并给你的长串字符（以 EEA1 开头）。整段复制粘贴到激活页输入框即可，码中的空格不影响识别；也可以请对方把激活码二维码对准手机，在手机上看到码后手动输入。输入错误会明确提示，不会消耗次数。

点「激活」并等待解锁

激活在本机离线完成（软件内校验签名），无需联网。成功后页面显示授权信息（是否永久 / 到期日）并自动进入首页；之后每次启动不再要求输入。

激活状态保存在哪里？ 保存在本机用户目录的 license.json，与软件目录无关——卸载软件、更换解压位置都不会丢失授权；删除该文件或换电脑后，用同一个激活码再激活一次即可（激活码不绑定电脑）。授权到期后软件回到待激活状态并给出到期提示，联系发放方续期即可。激活/验签全程离线，不向任何服务器发送激活码。
看到“API 未配置”不代表软件启动失败。这表示本地服务和知识库可能已经正常，只是尚未填写 DeepSeek Key。进入“设置”完成配置即可。

在 macOS 与 Linux 上使用

请下载跨平台版。软件主体是纯 Node.js 实现，因此绝大多数功能在 Mac 与 Linux 上与 Windows 完全一致。

安装步骤（macOS）

  1. 安装 Node.js 18 或更高版本：前往 nodejs.org 下载安装包，或执行 brew install node。
  2. 完整解压跨平台版压缩包。
  3. 双击目录中的 start.command。若提示「来自身份不明的开发者」，右键点击该文件再选「打开」，或在「系统设置 → 隐私与安全性」中点「仍要打开」。
  4. 浏览器会自动打开 127.0.0.1:7654；若没有，手动访问该地址即可。

若双击无反应，可在「终端」中进入解压目录执行 chmod +x start.command 后重试；解压工具偶尔会丢失可执行权限。

安装步骤（Linux）

  1. 安装 Node.js 18+，例如 sudo apt install nodejs npm。
  2. 安装中文字体以便导出打印 PDF，例如 sudo apt install fonts-noto-cjk。
  3. 解压后执行 chmod +x start.sh && ./start.sh。
拍照识题在 macOS 与 Linux 上需要云端 OCR。 Windows 的离线识图用的是系统自带的 Windows OCR，其他系统没有等价组件。软件会自动检测：非 Windows 时「设置 → OCR」中的「Windows 内置」选项会被置灰，并提示改用百度 OCR。也可以完全不识图，直接把题目文字粘贴进「题目文本」框，成文效果不受影响。
打印 PDF 依赖系统中文字体。 macOS 会自动查找宋体、冬青黑体、华文黑体、苹方等系统字体；Linux 会查找 Noto CJK 与文泉驿。找不到时会给出明确提示而不是产出乱码文件。注意 .otf 格式字体无法内嵌，请确保系统中存在 .ttf 或 .ttc 格式的中文字体。答题卡排版不受此限制，因为它的字体是随包内置的。
关于验证程度的说明。 跨平台改造的全部逻辑分支都有自动化回归覆盖，并已在 Windows 上确认原有功能没有回归。但作者没有 macOS 设备，字体自动查找与双击启动尚未在真实 Mac 上实测。若遇到问题，最可能出在这两处，欢迎反馈具体报错信息。

04 · Settings

首次设置：DeepSeek、千问视觉与 OCR

进入顶部“设置”页，按需填写服务凭据。所有凭据通过本机后端保存，不写入前端页面。

DeepSeek API

判断类模型：deepseek-v4-flash

润色类模型：deepseek-v4-flash

负责题型判断、内容规划辅助、骨架选择、成文与定向修订。

千问视觉 API

默认模型：qwen3.7-plus

负责识读漫画、图画、图表、可见文字、人物动作与具体数据，并标记不确定项。

OCR 后端

Windows 内置：离线、免费。

百度 OCR：需配置百度 API Key 与 Secret Key，复杂排版通常更稳。

推荐配置顺序

  1. 填写 DeepSeek API Key，保留判断类和润色类默认模型，点击“保存”。
  2. 点击“测试连通性”，看到模型、响应耗时和正常回复后再继续。
  3. 填写千问 / 百炼 Key，保留 qwen3.7-plus，点击“保存视觉设置”。
  4. 点击千问“测试连通性”。软件会用内置真题题图进行真实识读测试，不只是检查 Key 格式。
  5. 选择 Windows 本地 OCR 或百度 OCR，必要时填写百度凭据，然后点击“保存 OCR 设置”。
“保存”和“测试”是两件事。保存成功只表示配置已写入本机；必须再运行连通性测试，才能确认 Key、模型名称、网络和账户状态均可用。
不要把带有 config.json 的个人工作目录直接发给别人。需要发布或分享时，应使用不含个人 Key 的发布包，或先在设置页逐项点击“清除 Key”。

05 · Core Workflow

正确理解当前工作流

当前默认使用内容优先的 V2 成文链。语言骨架服务于内容，而不是反过来决定内容。

题面事实题型、任务、题图人物动作、图中文字、图表数值与不确定项
内容规划每段写什么、完成什么功能、引用哪些事实、是否为必写内容
语言骨架按修辞功能和适用范围为内容单元匹配表达骨架，处理冲突
成文自检生成三段式文章，并检查字数、覆盖、重复、事实、格式和双层来源
不要把软件描述成“选模板 → 填词 → 拼文章”的旧流程。 模板字典和组装练习仍然存在，适合学习与手动练习；但“开始解析并生成作文”的当前默认链路是题面事实 → 内容规划 → 语言骨架 → 成文自检。

事实层回答

题目到底要求什么？图上确实有什么？哪些数值能被验证？哪些地方看不清？

规划层回答

三段分别承担什么功能？每个任务是否被覆盖？原因、影响、建议是否重复？

骨架层回答

哪个句型适合表达这个内容单元？是否与题型、褒贬倾向、单图/双图、动态图/静态图冲突？

自检层回答

字数是否合格？图表数字有无来源？是否出现明显重复？每句能否追溯内容与语言来源？

06 · Write

输入题目与题图

“写作文”页支持图片上传、拖放、剪贴板粘贴和手动输入。图画/图表题应尽量带入原题图。

提供完整题目

可点击“上传题目照片”，把图片拖入虚线框，直接按 Ctrl + V 粘贴截图，或在“题目文本”中手动输入。

核对双通道识别

图片会进入 OCR 与千问视觉通道。软件会展示题型、画面描述、图表数据、主题推断及交叉校验提示。请人工核对 OCR 原文和不确定项。

选择运行方式

“只做题型判定”适合快速检查分类；“开始解析并生成作文”会运行完整的事实、规划、骨架、成文与自检链路。

图画和图表只有 Directions、没有视觉事实时，软件不会猜图。若缺少可核验的画面人物、动作、标注或图表数据，生成会提示“缺少视觉事实”。请上传清晰原图，或从真题题库使用“用这道题练习”带入题图。
图片建议：裁掉无关边缘，保持文字正向，避免强反光和严重透视；手机原图过大时可先截图再粘贴。单次图片请求上限为 24 MB。

07 · Facts & Plan

阅读题面事实与内容规划

这两步决定文章有没有“说对内容”。建议展开查看，而不是只跳到最终作文。

题面事实会整理什么

图画作文

客观画面、可见人物或物件、可见动作、图中文字、题目主题以及识读不确定项。

图表作文

图表类型、标题、单位、每个数据点、关键趋势或对比；未经视觉支持的数字不能写入文章。

小作文

收件对象、关系、语域、书信或通知格式，以及 Directions 中每一项必须完成的交际任务。

内容规划会展示什么

内容规划把全文拆成三个段落和若干“内容单元”。每个单元包含修辞功能、要表达的主张、事实证据、来源类型、预计字数、是否必写，以及用于防止同义重复的语义标识。若成文偏短，系统会优先增加新的论证维度；若偏长，则优先移除可选内容，而不是机械复制或删除关键任务。

判断内容是否可靠的快捷方法：画面描述应能在题图中直接看到；图表数字应逐项对应原图；小作文任务应覆盖 Directions 的每个动作要求。

08 · Language Skeletons

理解语言骨架

语言骨架是“如何表达某个内容单元”的结构参考，不是要求原样照抄的整段模板。

系统会从 372 条可用于生产的骨架中，根据作文轨道、段落位置、修辞功能、题型、褒贬倾向、单图/双图、动态图/静态图等条件筛选候选，再为每个内容单元绑定一个合适骨架。冲突组和语义标识会阻止全文同时出现互相矛盾或功能重复的骨架。

你会看到

  • 英文骨架及中文解释
  • 对应的内容单元
  • 来源、页码或来源条目标识
  • “为什么用”的匹配说明

你不应做

  • 为了保留骨架而牺牲题面事实
  • 把骨架中的示例人物和事件带进新题
  • 在一篇文章中堆叠多个同功能句
  • 把来源页码误当成文章内容来源
有的内容单元可能不绑定固定骨架。这不一定是错误；系统可以直接依据内容规划实现该信息点，避免为了“套句”而制造不自然表达。

09 · Result & Sources

查看结果、逐句来源与自检

生成结果不是只有一篇英文。它同时包含词数、自动检查和每一句的双层来源。

内容来源

说明这句话“写了什么、依据什么”：可能来自题干任务、题图可见事实、图表数据，或明确标注为分析、建议、展望等推理内容。

语言骨架来源

说明这句话“如何表达”：显示匹配的骨架、知识来源、页码或条目标识。它用于追溯表达结构，而不是替代事实依据。

在“生成结果”右上方勾选“显示逐句来源标注”，文章会按句展开。每句下方可同时看到内容单元与语言骨架信息。取消勾选即可恢复纯文章阅读。

当前自检项目

  • 词数是否落入系统接受区间
  • 所有内容规划单元是否在成文中得到覆盖
  • 是否存在明显重复的长短语或同义堆叠
  • 语义标识与冲突组是否重复
  • 图表数字是否都有题图数据支持
  • 小作文 Directions 任务是否逐项完成
  • 缺少视觉事实时是否避免编造具体画面
  • 是否保持三段结构与正确小作文格式
  • 每句是否同时保留内容来源与语言骨架来源
“自检全部通过”仍不等于无需人工复核。请至少再检查题意、专有名词、称呼与落款、图表单位、逻辑是否符合你的观点，以及是否有生硬或超出个人水平的表达。

10 · Word Count

字数规则

系统先读取题目中的显式字数，再按目标中点的 ±10% 计算接受区间。

接受区间 = 题目目标中点 × 90% ～ 110%（四舍五入）
常见题目字数要求及系统接受区间
题目要求计算方式系统接受区间
160–200 words中点 180；180 × 90%～110%162–198 词
about 150 words目标 150；150 × 90%～110%135–165 词
about 100 words目标 100；100 × 90%～110%90–110 词

生成时，系统还会把总字数预算分配给三个段落和各内容单元。偏短时，优先补充同一内容单元内部的具体因果、例证或影响，或增加不重复的新内容维度；偏长时，优先删除套话、重复意义、冗余例证与可选内容，并最多定向修订两轮。

题目中的显式要求优先。若 Directions 清楚写明一个范围或 about N words，系统按该要求计算；不要仅凭“英语一/英语二通常多少词”覆盖题面文字。

11 · Essay Review

批改作文：拍照上传，按讲义规则改

这个功能面向「你已经按这套方法论自己写完了一篇作文」的场景。软件先识别照片，交给你核对，确认后才依据讲义规则给出分级修改，并逐条说明修改依据。

三步流程

第一步 · 上传识别

拍照、截图或直接粘贴作文图片，点「开始识别」。也可以点「跳过识别，手动输入」直接把作文敲进去。

第二步 · 校对确认

识别结果会填进可编辑文本框。请务必先核对，改成你实际写的内容。题型会自动判定并显示依据，可手动改选。点「确认文本并开始批改」后才会进入批改。

第三步 · 批改结果

查看分档、得失分点与分级修改项，逐条采纳或忽略，生成终稿，可复制、导出报告 PDF 或直接送入答题卡排版。

批改一定发生在你确认之后。 第二步的确认按钮是唯一入口，软件不会拿未经你核对的识别结果直接开始批改。手写识别常有错字与断词，这一步不能省。

选定真题批改（推荐）

第二步提供两种模式。选「对照真题批改」后，依次选择英语一 / 英语二 → 大作文 / 小作文 → 年份 → 具体题目，软件会自动带入该题的官方题干、图表原始数据与校对范文，无需你手填题型或题干。

  • 字数与任务校验更准：直接用官方 Directions 判断「at least 150 words」这类硬性要求。
  • 图表数字可核验：用题库权威数据判断你写的百分比是否真实存在，而不是靠识图。
  • 可与范文对照：对比字数差距、段落数、模块覆盖，并列出范文用过而你没用的表达。

题目下拉会标注「有范文 / 无范文」。60 道题有校对范文；其余题目仍可用官方题干校验，但不做范文对比，也不会编造范文。若你写的是自拟题目，切到「不指定真题」手选题型即可。

分项估分

批改结果会给出四个维度的估分区间，大作文按 20 分制、小作文按 10 分制：

四个评分维度
维度占比主要看什么
内容30%任务是否写全、图表数字是否可核验、字数是否达标
结构25%三段式是否完整、写作模块是否覆盖
语言30%语法错误数量、重复表达、表达是否可升级
格式15%称呼落款、大小写与标点

每项都给区间而不是确定分数，并附扣分原因，方便你看出弱在哪一项。

分数是估算，不是阅卷分。 分项估分依据本软件的讲义规则、语法规则与自检项计算，用途是定位问题。真实阅卷还包含卷面、逻辑深度、表达地道程度等无法用规则衡量的因素，请不要把这个区间当成预测分。

每条修改都有依据

这是本功能的核心约束。每条修改项都会显示「修改依据」，且依据只能来自以下五类，不存在模型自由发挥：

  • 讲义功能句：给出骨架编号与讲义页码，可点击打开原扫描页核对。
  • 讲义词表：词汇替换只从 207 个讲义词条中取，词表里没有的表达一律不建议，不会凭空造「高级词」。
  • 讲义易错提醒：如「结尾段功能是表达期待与致谢，不要再引入新信息」，附原文与页码。
  • 语法规则：标注具体规则名（主谓一致、冠词、时态等），片段必须能在你的原文中定位。
  • 软件自检规则：字数规则、图表数字校验、重复表达检测、模块顺序，与生成作文时用的是同一套规则。

没有可追溯依据的条目不会出现在结果里。这一约束有自动化回归保障（scripts/verify-essay-review.mjs）。

修改前后对比

每条修改项都以「原文（删除线）→ 改为（高亮）」呈现。采纳后，页面底部会列出实际替换了哪些内容，并给出完整终稿。含占位符的讲义功能句不会被直接写进终稿——否则终稿里会残留 {题目相关词}；这类条目会归入「需要你自己动笔」清单，并把模板一并显示出来。

关于分档。 除分项估分外，还会给出一个总体档位（接近满分档 / 中上档 / 中档 / 需大改）与得失分点清单，同样属于估算，用于快速定位问题。

手写照片怎么识别

手写作文默认走视觉模型转写，而不是本地 OCR。原因是实测下来两者差距很大：

同一张旋转 90° 的连笔手写照片
识别通道结果
Windows 内置 OCR可辨认字符仅 35%，输出 D 巴 ' 乙 夕 这类乱码
视觉模型（千问）完整转写，96 词，无法辨认 0 处，并自动纠正了旋转
  • 照片横躺也能读：视觉模型会自行判断阅读方向。界面会告诉你它检测到旋转了多少度。
  • 只转写不改写：转写时严禁修改语法、拼写与用词，你写错的地方会原样保留——那正是后面批改要处理的。
  • 看不清就标记：辨认不出的词会写成 [?]，不会猜测填词。
  • 本地 OCR 作兜底：没配置千问视觉 Key 或调用失败时，会自动回退到本地 OCR，并提示你配置 Key 可大幅提高准确率。
  • 还可以手动旋转：上传后有「左转 / 右转 90°」按钮；转过之后软件会尊重你选的方向。
识别质量不佳时会如实告警，绝不假装成功。 无论走哪个通道，只要结果中可辨认字符比例过低，软件都会保留原始结果、跳过文本清洗并明确提示——因为让模型去「清洗」一堆乱码，它会脑补出一篇通顺但你从未写过的作文，那样批改就毫无意义。此时请换正面平铺、光线均匀的照片重拍，或直接手动输入。

13 · Knowledge Base

知识库：学习卡片、行文解析、字典与组装演练

知识库适合检索、背诵、理解来源和主动组句。它与自动成文链互补，但不是自动成文的旧式拼接入口。共有五个子页面：模板字典、学习卡片、行文解析（真题范文精讲）、模块组装与组装演练。写完作文后的复盘则直接出现在「写作文」页。

先选备考方向：英语一还是英语二

首次打开软件会让你先选择备考方向，之后可在「设置 → 备考方向」随时切换。选定后知识库只显示你需要背的内容，进度条也能真正背满，而不是永远停在一个填不满的大池子里。

划分依据是讲义来源与真题实际考查情况，共分三类：

  • 英语一专属（80 条）：石雷鹏英语一大作文与英语一小作文笔记。
  • 英语二专属（72 条）：石雷鹏英语二大作文与英语二小作文笔记。
  • 英语一二通用（220 条）：原扫描讲义的功能句，两个方向都要背。
备考方向主线（计入进度）拓展（默认不计入）可背总量
英语一图画大作文 + 小作文，295 条图表 5 条300 条
英语二图表大作文 + 小作文，273 条无273 条

为什么英语一仍保留图表模板：英语一 2024 年考过图画与图表的混合题、2025 年考过图表题，所以图表模板不会被隐藏，而是作为「拓展题型」保留。它默认不计入进度，勾选卡片页的「纳入拓展题型」即可一并背诵。英语二从未考查图画大作文，因此完全不显示图画模板。

两个方向的背诵进度分别保存：切换方向时，两边已标记的状态都不会丢失，各自都能背到 100%。

学习卡片：按学习进度背模板

「学习卡片」把当前方向需要背的功能句骨架，按轨道顺序与每条轨道内部的模块顺序线性铺开，再按你设定的每日数量切成学习单元。背诵顺序因此等于实际写作顺序，不会出现先背结尾句、后背开头句的情况。每张卡片都标注它属于英语一专属、英语二专属还是通用。

  • 每天背多少：可选 5 / 8 / 12 / 16 / 20 张，改动后单元数会立即重算。默认 8 张，共 47 个单元。
  • 三种状态：已掌握、需复习、重置。顶部进度条与统计会实时更新。
  • 自测模式：勾选后中文译文会被模糊遮挡，鼠标悬停可临时查看；也可对单张卡片单独隐藏或显示中文。
  • 四个筛选器：轨道、模块、状态、单元。多个筛选条件是「同时满足」关系，例如「第 1 单元 + 图表作文」只会显示同时符合两者的卡片。
  • 来源可查：每张卡片都标注讲义页码，点击即可打开对应扫描原页核对。

进度存在哪里：学习进度保存在软件目录下的 knowledge/study-progress.json，属于服务端文件。因此换浏览器、清浏览器缓存都不会丢；同一局域网内访问同一个服务也能看到同一份进度。想从头开始可点「重置进度」，该操作不可撤销。

调整每日数量或轨道范围时，已经标记过的卡片状态会被保留，不会因为改计划而清零。

成文之后：行文复盘与本次用到的模板句

行文解析属于「写完之后」的复盘环节，因此它直接出现在「写作文」页的生成结果下方，不需要你再去题库另选题目。

行文复盘以模块组装的视角呈现这篇作文：

  • 模块组装流程条：把该轨道 6 个写作模块横向排开，标出每个模块由本篇哪几句承担。绿色为已覆盖，红色为必需但缺失，虚线为未使用的可选模块。
  • 缺口建议：缺哪个模块就直接告诉你该补一句什么功能，把复盘变成可执行的修改动作。
  • 逐句拆解：每句显示所属模块、功能标签、这句为什么要放在这个位置，以及它实际套用的讲义模板与页码。
  • 没有套用讲义模板的句子会如实标注「由内容规划直接实现」，不会硬凑一个来源。

本次用到的模板句会把这篇作文真正套用过的模板逐条列出，可以单条标记「已掌握 / 需复习」，也可以一键「全部标记已掌握」。标记结果直接写入同一份学习进度，知识库「学习卡片」页的进度条会同步更新——写一篇作文就等于顺手复习了这几张卡片。

真题范文精讲：解释每道题为什么这样写

知识库的「行文解析」子页面用于对照学习已校对的真题范文，针对 60 道有范文的真题逐句说明功能、位置理由与对应讲义页码。解析默认完全离线生成，只使用题库范文、题面事实与讲义骨架，不联网也能用。

  • 行文骨架：先给出该题型三段各自的任务与需要避免的写法，例如图表题第一段不要在描述数据时提前分析原因。
  • 逐句功能：如客观描图、图中文字解读、寓意点题、数据描述、总体判断、原因分析、影响分析、建议措施、展望收束、格式落款。
  • 题面事实：数据句会标出本句实际引用了哪些图表数据；描图句会标出题图上的文字。
  • 字数分配与模块覆盖：显示各段词数占比，并列出该轨道六个模块中哪些已覆盖、哪些未覆盖。
  • AI 深化讲解（可选）：勾选后会在离线结论之上补充句间衔接与常见易错点。它被限制为只能补充讲解，不能新增范文没有的句子，也不能改写离线的功能判定。未配置 Key 或调用失败时会自动回退到离线解析。

在「真题题库」页打开任意题目后，点「看行文解析」可直接跳转到该题的解析。若该题暂无已校对范文（共 14 道），软件会明确提示，并只提供题型结构解析，不会凭空编造范文。

14 · Real Answer Sheet

真实答题卡：模拟考场与红字字帖

把作文直接叠加到原版考研英语写作答题卡区域。边框、上下警示语、Section 标题、题号、横线和整体比例全部保留，并可导出单页 A4 PDF 或高清 PNG。

四套原版区域

可选英语一/英语二的 Part A、Part B。英语一每栏 24 行，英语二每栏 23 行，均包含题号所在首行。

23 个内置字体

完整内置 Dome 的 21 个 TTF 字体，并保留 Ink Free、Segoe Script；默认推荐“舒窈英文衡水体”，可直接查看字体试写。

两种快捷场景

“模拟考场”一键恢复黑字 17pt；“红字字帖”一键切换红字 18pt。两种模式都可继续微调字号、倾斜与基线。

操作方法

  1. 选择答题卡区域。小作文通常使用 Part A，大作文和图表作文使用 Part B。
  2. 点击“模拟考场”或“红字字帖”载入推荐参数，再选择字体、颜色、12–28pt 字号、0–15° 倾斜角度和 −4～+4pt 基线微调。
  3. 从“写作文”页点击“生成答题卡排版”可自动带入正文与题型；也可以直接编辑文本、称呼、落款、标题、日期和齐头式/缩进式格式。
  4. 点击“生成预览”核对完整答题卡与“已用 / 可用行数”；确认无溢出后下载 A4 PDF 或 2 倍分辨率 PNG。
这里不是重新画几条横线。网页预览、PDF 和 PNG 都使用原答题卡完整背景，再叠加内嵌 TTF 的矢量文字；免安装版运行时仍为纯 Node，无需安装 Python 或字体。
模拟考场看真实密度，红字字帖用于临摹。建议先用默认舒窈英文衡水体和快捷参数生成，再根据实际字形用“基线微调”上下移动少量距离；不要用倾斜角度代替字体本身的书写风格。

15 · Quick Checklist

快捷检查清单

每次练习按下面顺序快速检查，可显著减少“识图错、任务漏、字数偏、格式错”。

生成前

  • 题干完整，Directions 没有漏行
  • 题图清晰、方向正确、无遮挡
  • OCR 文字与原图逐项核对
  • 图表单位、年份、百分比已确认
  • 千问视觉不确定项已人工判断
  • DeepSeek 与千问测试均正常

生成后

  • 三段功能清楚，没有同义重复
  • 小作文每项任务都已完成
  • 具体画面和数字都能回到题面
  • 词数落入本题接受区间
  • 逐句内容来源与语言来源可解释
  • 称呼、落款、通知标题和日期正确
最稳妥的复盘顺序：先看“题面事实”，再看“内容规划”，然后看“语言骨架”，最后阅读成文和自检。只看最终作文会错过软件最重要的纠错信息。

16 · Privacy

隐私、数据流向与 Key 安全

软件界面和知识库在本机运行，但启用 AI 或云 OCR 时，相应数据会发送给你选择的服务商。

不同功能的数据处理位置
功能 / 服务会处理或发送的数据不会主动发送的内容
Windows 本地 OCR题目图片在本机 Windows OCR 引擎中识别。不会因 OCR 本身把图片发送到百度。
千问视觉上传或粘贴的题目图片，以及“请识读题图”的指令，会发送给千问 / 百炼视觉接口。不会主动上传整个项目目录或整份知识库。
DeepSeek题目文本、结构化题面事实、内容规划请求、候选语言骨架与绑定上下文、当前草稿及定向修订要求等，会按生成步骤发送给 DeepSeek。不会主动上传本机其他文件或整份原讲义图片。
百度 OCR当选择云端 OCR 时，题目图片会发送给百度 OCR；鉴权时使用已配置的百度凭据。不会因百度 OCR 自动发送你的作文知识库。
激活 / 授权激活码只在本机校验（离线验签），不向任何服务器发送；授权状态写入本机用户目录的 license.json。不会上传激活码、不联网校验、不读取本机硬件信息。

Key 存放位置

通过设置页保存的配置写入项目根目录的 config.json。前端读取配置状态时只获得掩码，不会返回 Key 明文。正式发布包不应包含任何个人 Key。

  • 不要截图、直播或录屏展示完整 Key
  • 不要把个人 config.json 上传到网盘、论坛或代码仓库
  • 分享软件前，在设置页清除 DeepSeek、千问和百度凭据
  • 若 Key 曾出现在聊天、截图、日志或公开仓库中，应立即到对应平台撤销旧 Key，再创建新 Key
  • 定期检查调用量、余额和异常请求
泄露后的正确处理不是“把截图删掉就行”。一旦怀疑 Key 已泄露，请立即在服务商控制台撤销或删除该 Key；之后再清理本机配置、历史文件和公开记录。

17 · FAQ

常见问题

以下问题覆盖激活、启动、缓存、鉴权、视觉识读、字数、自检与完整版原页。

1. 提示端口 7654 已被占用，怎么办？

先关闭重复启动的命令窗口或已运行的软件实例，再重新双击 start.bat。如果确实需要改端口，可修改 config.json 中的 server.port，然后用新端口访问本机地址。不要同时启动多个占用同一端口的实例。

2. 页面显示旧界面、按钮不更新或布局异常，怎么办？

先按 Ctrl + F5 强制刷新，跳过浏览器缓存。仍异常时，确认命令窗口运行的是当前解压目录，并检查是否把新旧版本文件混在同一文件夹中。

3. DeepSeek 返回 401，是什么意思？

401 通常表示 Key 无效、已撤销、复制时多了空格，或配置的账号无权使用当前接口。回到“设置”重新填写并保存，再点“测试连通性”。若 Key 曾泄露，先在平台撤销旧 Key，再使用新 Key。

4. 为什么保存了千问 Key，仍然看图失败？

请单独点击千问区域的“测试连通性”。该测试会实际读取一张内置真题题图，可同时验证 Key、模型、网络和账户权限。默认模型是 qwen3.7-plus。如果测试失败，不要只反复保存；应根据返回信息检查凭据、余额、区域权限或模型可用性。

5. OCR 不准或完全识别不到文字，怎么办？

先把图片裁正、提高对比度、去掉大面积空白，或直接使用屏幕截图。Windows OCR 适合清晰中英文文字且完全离线；复杂排版可切换百度 OCR。无论使用哪种 OCR，都要在提交生成前人工核对题目文本、数字和单位。

6. 为什么提示“缺少可核验视觉事实，不能猜图”？

Directions 只说明“根据下图写作”，并没有提供图中人物、动作或图表数字。当前软件禁止根据历年真题记忆猜画面。请上传题图，或从真题题库点击“用这道题练习”带入原图。对于题库内已有校对资料的题目，后端可在特定条件下使用离线事实摘要兜底。

7. 为什么 160–200 词不是允许写到 200，而是显示 162–198？

系统把 160–200 的中点 180 作为目标，再按 ±10% 计算接受区间，因此是 162–198。类似地，about 150 对应 135–165，about 100 对应 90–110。这是软件当前的生成与自检规则。

8. 自检有一项未通过，文章还能用吗？

先查看具体失败项。字数、任务覆盖、视觉事实、图表数字和小作文格式属于高优先级问题，应修正后再使用；重复表达或个别来源展示异常也需要人工复核。软件可能自动扩写、收缩或定向修订，但最终决定仍应由你根据题目检查。

9. 为什么点击来源页码看不到原讲义图片？

47 页原讲义图只包含在完整版。精简版和免安装版仍保留结构化来源信息，但不包含原扫描图片，因此点击原页可能无法打开。需要逐页核对时，请使用完整版。

10. 浏览器关闭后，软件还在运行吗？

只要启动时的命令窗口仍然开启，本机服务通常仍在运行，重新访问 127.0.0.1:7654 即可。要完全停止，请回到命令窗口按 Ctrl + C 或关闭该窗口。

11. 组装演练为什么刷新或关闭后内容丢失？

组装练习稿保存在当前浏览器会话中，设计目标是临时练习，不是长期文档存储。重要内容请及时点击“复制纯文本”，保存到自己的笔记或文档。

12. 答题卡 PDF 或 PNG 无法下载，怎么办？

先点击“生成预览”，确认页面出现完整答题卡且行数状态正常，再下载 PDF 或 PNG。若浏览器拦截下载，请允许该本机页面下载文件。23 个字体都已内置，无需在 Windows 中安装；若某次下载中断，可刷新页面后用默认“舒窈英文衡水体”重新生成。若提示溢出，请先缩小字号或精简内容。

13. 激活码是什么？从哪里获得？

激活码是以 EEA1 开头的一长串字符，由软件发放方（作者）为你的授权生成，内含有效期限。正式发行包首次使用必须激活；向发放软件的作者购买或索取即可。激活全程离线、不绑定电脑，同一码在任意一台电脑上都能激活。

14. 换电脑、重装系统或删除 license.json 后需要重新激活吗？

需要，但只是把同一个激活码重新输入一次，秒级完成，不消耗次数也不联网。授权状态文件保存在本机用户目录，不在软件文件夹内，因此删除软件不影响已激活状态；只有当该文件丢失或换到新电脑时，才需要再次输入激活码。已过期的码无法再次激活，需联系发放方续期。

15. 提示激活码无效或已到期，怎么办？

先确认没有复制漏字符或混入空格以外的符号（码中的空格不影响识别）。仍无效或显示已到期时，把整段码发给发放软件给你的作者核对——作者可用签发工具同源验签确认码是否有效、何时到期。激活码离线授权、无法远程延期，到期续期＝发放方签一个新码。
